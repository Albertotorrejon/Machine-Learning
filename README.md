# Machine learning

Supervised learning on two biomedical problems, one in R and one in Python.

| File | Content |
|---|---|
| `PEC1_Machine_learning.Rmd` | **Protein secondary structure prediction with k-NN** (R: class, caret, pROC). Sequence windows one-hot encoded, k tuned, evaluated with confusion matrices and ROC curves. Report: `PEC1_Machine_learning.pdf`. |
| `PEC_2_MACHINE_LEARNING.ipynb` | **Parkinson's disease severity from voice features with a dense neural network** (Python: pandas, scikit-learn, TensorFlow/Keras). Min-max scaling, train/test split, MLP training and evaluation. Report: `PEC 2 MACHINE LEARNING.PDF.pdf`. |

---
Coursework for the MSc in Bioinformatics and Biostatistics (Universitat Oberta de Catalunya). Reports are in Spanish.
